# Shattered Shield

Shattered Shield is an MMORPG with a heavily enhanced Cube 2 engine: class-based armor and weapons, split-body character models, PvP battlegrounds (CTF, KOTH, TFF), combination crafting, and a WoW-style UI with add-ons.

The design blueprint lives with the project records (MMORPG Features & Function Design Guide). Art direction is the Quaternius low-poly style base, with the Quaternius Universal Animation Library 2 as the animation library.
