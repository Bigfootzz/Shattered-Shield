# Shattered Shield

Shattered Shield is an MMORPG built fresh on the Revelade engine (Cube 2 / SDL2).

Shattered Shield and Revelade Revolution are completely separate products with their own repositories, releases, and download pages. Engine improvements made here are expected to flow back into the Revelade engine codebase.

The design blueprint lives with the project records (MMORPG Features & Function Design Guide). Art direction is the Quaternius low-poly style base, with the Quaternius Universal Animation Library 2 as the animation library.
